# 阅读指南：从网络模型到有边界的研究问题

核验截止：2026-10-02。这是一条面向初学者的分阶段路线，可按基础和可用时间调整。先用手算和纸上建模掌握输入、约束、算法及证据，再决定是否开展实验。[领域综述](review.md)解释主要公式，[代表与前沿研究](representative-research.md)提供公开论文来源。本指南选择代表材料，不声称完整覆盖所有边缘与数字孪生研究。

## 阶段一：建立术语与时间轴

先读Mach与Becvar综述的系统架构及卸载分类，再读AoI综述引言和定义。画“设备—接入点—边缘服务器—远端云”图，标出各层计算、内存、带宽和能量限制；再画生成、发送、收到、处理与返回的时间轴。

手算一次卸载时延，画三次更新的信息年龄锯齿图。检查数据量和传输速率的单位。阶段目标是能解释：服务器计算快为什么仍可能响应慢，信息年龄为什么不等于网络时延，以及孪生状态同步为什么需要资源。

## 阶段二：阅读三个核心优化问题

建议顺序为预算同步R176→新鲜度R164→无服务器查询R160。每篇分三遍阅读：摘要与系统图，模型与主定理，算法步骤与实验设置。公开来源和所读作者稿页码见综述。

R176先看第1、4–5页，理解每轮预算与对象同步选择；R164第1–4页辨别静态近似、动态竞争和会议到期刊扩展；R160第1–4页理解短寿命函数、数据切分、在线内存调整及测试床。

每篇写一页方法卡：输入、决策变量、目标、容量、是否知道未来、允许拒绝请求与否、比较基线、证明条件、实验平台。未读到的内容写“待读”。特别标注资源违反是否允许、数据量是否预测以及预测误差是否参与评测。阶段目标是能指出改变哪一项条件后，原定理就不能直接使用。

## 阶段三：连接预测与系统决策

从模型重训与推理、移动迁移、容错备份、隐私约束中选一至两条线，先看代表研究及论文阅读卡，再选择全文。赵翔宇等的轨迹、流量和移动服务研究可作为时空预测输入的交叉阅读；单纯预测状态不等于建立数字孪生。

李韬等的[分布式不可分在线凸优化](../papers/P145.md)、[TTC-X摄像控制](../papers/P153.md)和[DT-DIMA交通风险孪生](../papers/P149.md)提供另一组系统问题。TTC-X所读作者版的PiCOL采用有限动作指数权重在线学习；预测器离线训练、控制器在线调整，不要仅据作者主页概括为连续凸优化。DT-DIMA早期预印本与正式题名、摘要数值不同，引用时绑定具体版本。

建立“预测输出→资源或感知决策→服务结果”表，对每个箭头分别标明直接评测、模型假设或尚未验证。比较近似比、竞争比和遗憾时写出比较对象；比较延迟时同时记录接纳率，避免把拒绝更多请求造成的低延迟视为普遍改善。

## 阶段四：形成可检验的问题

选一个小场景，例如两台边缘服务器、三类请求和固定计算/能量预算。列出完美预测与错误预测下的不同决策，再设计敏感性实验。可分别改变预测误差、链路波动或迁移开销，保持请求轨迹和计算预算一致。

产出一页模型复述、一页待验证假设和一页评测设计。评测可包括接纳率、尾延迟、能源、同步开销与容量超限；每项指标应说明单位和测量范围。纸上小例子帮助理解，但不能写成已经完成的系统复现或部署。

## 遇到困难时

不懂网络图，先标数据路径和单位；不懂优化式，逐个解释变量由谁决定、约束为何存在；不懂随机舍入，用两个任务手算超容量概率；不懂理论界，先找条件和比较者。阅读新论文时重新核对作者、正式/预印本状态与修订日期，本指南核验截止之后的进展需要另行检查。
